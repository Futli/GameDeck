# GameDeck

Онлайн-комнаты для настольных игр на костях с синхронизацией в реальном времени. Игроки создают комнату, подключаются по ссылке, ходят по кругу и видят результат у всех одновременно. Целевая платформа — Telegram Mini App.

> **Статус:** ранняя стадия разработки. Первая игра — «бросок кубика»: побеждает наибольшее значение, при ничьей перебрасывают только лидеры.

## Возможности

**Сейчас в работе (MVP)**

- Создание комнаты и вход по коду или ссылке
- Хост комнаты: выбор игры, ставка, пароль, лимит игроков (до 6), исключение игроков
- Старт игры, ходы по кругу, объявление победителя
- Состояние комнаты синхронизируется через WebSocket, сервер — единственный источник истины
- Стол на 6 мест: свой коврик всегда снизу, в центре — информация об игре

**Дальше по плану**

- Telegram Mini App: авторизация через `initData`, оплата в Telegram Stars
- Виртуальные монеты (без вывода), рейтинг и статистика игроков
- Пиксельные коврики 128×64 с кастомизацией
- Приглашения и реферальная программа
- Новые игры: перудо, тысяча на костях, покер на костях

## Стек

| Слой | Технологии |
| --- | --- |
| Язык | TypeScript (strict) во всех пакетах |
| Сервер | Node.js LTS, Fastify, Socket.IO, zod |
| Клиент | React, Vite, чистый CSS (без UI-фреймворков) |
| Общий код | Пакет `shared`: типы событий, схемы zod, игровая логика |
| Тесты | Vitest |
| Монорепо | pnpm workspaces |
| Хранение | Состояние в памяти процесса (БД появится вместе с рейтингом) |

## Архитектура

```
gamedeck/
├── packages/
│   ├── shared/   # контракт клиент ↔ сервер: типы, zod-схемы событий, правила игр
│   ├── server/   # Fastify + Socket.IO: комнаты, очередь ходов, авторитетный бросок
│   └── client/   # Vite + React: лобби, стол, коврики игроков
├── package.json
└── pnpm-workspace.yaml
```

Ключевые решения:

- **Авторитетный сервер.** Клиент только отправляет намерение («бросить кубик»), а сервер проверяет очередь хода, генерирует результат и рассылает новое состояние комнаты. Подделать бросок на клиенте нельзя.
- **Типизированный контракт.** События Socket.IO описаны в `shared` один раз и используются с обеих сторон. Входящие данные на сервере валидируются через zod.
- **Игры как модули.** Каждая игра реализует общий интерфейс (начальное состояние, допустимые ходы, применение хода, проверка победы). Стол и лобби не зависят от конкретной игры, поэтому новую игру можно добавить без переделки интерфейса.
- **Логика без I/O.** Правила игр — чистые функции, их легко покрывать юнит-тестами.

## Запуск

### Требования

- Node.js 22 LTS или новее
- pnpm 9+ (`corepack enable` включит его вместе с Node)

### Установка

```bash
git clone https://github.com/Futli/GameDeck.git
cd GameDeck
pnpm install
```

### Режим разработки

```bash
pnpm dev
```

Поднимает сервер и клиент с hot reload:

- клиент (Vite): http://localhost:5173
- API и WebSocket: http://localhost:3000 (Vite проксирует запросы к нему)

### Продакшен-сборка

```bash
pnpm build
pnpm start
```

Сервер отдаёт собранный клиент и WebSocket на одном порту: http://localhost:3000.

### Доступ с других устройств (Tailscale)

Сервер слушает `0.0.0.0`, поэтому приложение доступно по IP машины в сети Tailscale:

```bash
tailscale ip -4          # например, 100.64.0.10
# затем открыть в браузере: http://100.64.0.10:3000
```

Так можно играть с телефона или с другого компьютера без публикации сервера в интернет.

### Переменные окружения

| Переменная | По умолчанию | Описание |
| --- | --- | --- |
| `HOST` | `0.0.0.0` | Адрес, на котором слушает сервер |
| `PORT` | `3000` | Порт HTTP и WebSocket |
